# Form and musical development

Flexible DESIGN library, not mandatory forms or an official tag grammar. Choose syntax through [SUNO_TAGS_lib.md](../references/SUNO_TAGS_lib.md). Omit, combine, reorder or replace sections when the user's concept requires it.

## Section card

Plan function → energy/density → active parts → foreground theme/voice → change → exit. Convert this working card into audible directions; do not print six administrative fields as code in Lyrics.

| Section | Function | Development and boundary |
|---|---|---|
| Intro | Establish space, timbre, pulse or a motif fragment | Start with one part, an incomplete idea or gradual groove; neither long nor voiceless by definition |
| Verse | Advance the situation and leave room for words | Clear rhythm/bass, restrained lead; later verses add a detail, perspective or consequence |
| Pre-Chorus | Change anticipation | Register, rhythmic density, harmonic tension or withdrawal; growth need not mean louder |
| Chorus | State the central idea and recognizable phrase | Contrast through longer vowels, simpler words, broader melody or texture; not necessarily the loudest section |
| Post-Chorus | Continue the chorus impulse | Motif, answer, chops or instrumental tail; may carry the main dance hook |
| Build | Prepare a change of state | Bass withdrawal, gathering hats/snare, filter opening or register rise; reserve room for release |
| Drop | Establish arrival or return | Kick/bass, main theme or sharp contrast; a sparse drop is valid |
| Breakdown | Open space and reconsider the theme | Remove selected rhythm/bass parts, retain voice/pad/motif; choose a fresh route out |
| Break | Interrupt or spotlight the groove | Stop, fill, drums alone or silence; distinct from a chopped breakbeat |
| Interlude / instrumental break | Connect sections and rest the words | Instrumental answer, new motif color or texture; identify the next entrance |
| Bridge | Change musical or narrative perspective | Harmony, register or role contrast; may be quiet, solo or spoken |
| Solo | Give an instrument the foreground | Specify source, motif/articulation and support; new harmony is optional |
| Plateau — a function | Sustain the achieved groove/energy | Small hat, bass-ending or response changes; no invented mandatory tag |
| Final Chorus | Return after the song's development | Keep identity; vary a final line, octave, response or layer when useful |
| Outro | Complete the emotional/musical action | Withdraw parts, leave a motif, stop or fade according to the intended ending |

## Development mechanisms

Choose a few purposeful mechanisms, not every option: motif fragment → full phrase → answer/revoicing; change active roles or event density; move register; shift accents, subdivisions or half-time feel without automatically changing BPM; prolong harmony or delay resolution; change attack/filter/space; remove support before a return; contrast restrained verse with open chorus or recitative with melody. An octave shift is not a key change. Space for the singer also develops the arrangement. Avoid an identical riser at every boundary. Detailed prompts may describe movement within a section while remaining concise.

## Adjustable skeletons

| Task | Possible form | Characteristic development |
|---|---|---|
| Club instrumental | Intro → Build → Drop/plateau → Breakdown → Build → varied Drop → Outro | Change one salient role or response at the second arrival |
| Short rave | Intro → main instrumental groove → brief withdrawal → return → Outro | One leading stab/bass figure; rap is optional |
| Pop / eurodance | Intro → Verse → optional Pre-Chorus → Chorus → optional Interlude → Verse → Chorus → optional Bridge → Final Chorus → Outro | Verses advance meaning; returning hook joins music and words |
| Rap | optional Intro → Verse → Hook → Verse → Hook → Outro | Dense verse versus simpler sung/spoken hook, often 1–4 lines; no quota |
| Chorus ballad | Intro → Verse → Chorus → Verse → Chorus → Bridge → Chorus/Outro | Renew meaning/articulation without compulsory volume escalation |
| Through-composed ballad / folk | Intro → Verse → Verse → Interlude → Verse → Outro | Shared motif or embedded refrain; a separate chorus is optional |
| Blues | Intro → vocal/response cycles → optional Solo → closing cycle → Outro | Phrase and call-response development; twelve-bar form is optional |
| Ambient / cinematic | Intro → gradual development → peak/turn → residual motif → Outro | Timbre, space and register may replace a conventional drop |

## Event example

Original illustration, not a preset: present the motif without bass, return it over a groove, then let another timbre answer after the breakdown.

```text
[Intro]
[Synth: sparse plucked motif]
[Build]
[Drums: hats gather, snare rises]
[Drop]
[Bass: steady offbeat pulse]
[Synth: full motif, bright lead]
[Breakdown]
[Synth: motif thins into soft pad]
[Build]
[Transition: short roll, kick returns]
[Drop]
[Keys: answer the returning lead]
[Outro]
[Synth: last motif fades]
```

These are estimated medium-risk cues, not a score. Styles supplies palette and genre groove rather than duplicating every event. A short request may need only a few lines.

## Emotional trajectory

Added 2026-10-04; M02/M04 in [SOURCES_lib.md](../references/SOURCES_lib.md) inform this DESIGN method. Extend the same section card; do not require another plan. At significant boundaries choose before/after states and the audible cause of change.

| Axis | Possible movement | Consistency check |
|---|---|---|
| Density | Remove a bed, add a response, combine roles | Main phrase remains distinct |
| Register | Raise/lower a line, widen spacing | Key does not change automatically |
| Event rate | Sparse accents ↔ subdivisions | BPM/meter may stay fixed |
| Harmonic stability | Grounding → anticipation → chosen closure | Appropriate to the harmonic language |
| Distance/articulation | Close dry voice → spacious held response | Preserve the meaningful accent |
| Theme presence | Fragment → full phrase → residual gesture | Retain a recognizable invariant |

Do not raise every axis in every chorus. A quiet phrase, new harmonic meaning or first complete motif can be the climax. Plateau sustains a chosen state through small changes; continuous forms need no separate chorus.

## Transitions as connected actions

| Mechanism | Specify |
|---|---|
| Pickup | Who starts early, the destination and who yields |
| Fill / instrumental pickup | Source, function and expected entrance |
| Held note or tail | What continues and what enters over it |
| Withdrawal / pause | Parts removed and parts returning |
| Bass-motion change | Harmonic relation and the new pattern's entrance |
| Phrase overlap | Separate ending/starting roles so words remain clear |
| Timbre / FX gesture | Purpose and location; FX does not replace all other connections |

Select one defining mechanism or a compatible combination. Overlap is a desired scenario, not guaranteed editing accuracy. Mark each new singer explicitly at a vocal handoff. Musical suitability does not lower a cue's syntax risk.

## Return and ending

A return retains identity and, when development is needed, changes an ending, response, texture or harmonic support. Changing all is unnecessary. Decide whether the outro closes, leaves a residual gesture, loops openly, dissolves or stops; fade is not universal.

A targeted revision must respect approved form and locks. The existing COMPOSE review checks why the change occurs, what connects sections and whether entrances are clear; it does not start a second composition pass. Without audio, verify the written sequence, not performance.
