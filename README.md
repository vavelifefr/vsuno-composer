# Vave Suno Composer

Portable skill for Suno prompts: musical form, main theme, arrangement, explicit vocal parts and original lyrics. Skill/native folder name: vsuno-composer; Codex invocation: $vsuno-composer. Console launcher: vsuno.cmd. Accepts conversation, structured briefs, earlier chunks and musical references; outputs the existing five-field parser contract.

Music and lyrics have independent strict/balanced/free modes. Supports immutable versions/IDs, mixing word/music donors, literary or literal translation, safer prompt revisions after reported failures, and separate text/highlight views. Real reference artists/titles stay private and never enter final chunks.

Complete supplied chunks also support revision without archive access. Limited environments use honest context-only metadata rather than invented IDs/counts. Local archive/list/get can use an explicitly authorized --data-root; default storage remains this project, with no migration or fallback.

Provide accessible instructions or the full text export plus a musical brief. Typing a Windows path in a cloud chat does not grant disk access. Reading the skill requires no CLI/program execution. Local helpers require Python 3.9+; from the project root run .\vsuno.cmd --help. Interactive start also requires an already installed/configured Codex CLI. Installation, PATH and account settings are separate authorized tasks.

New text is UTF-8. Lyrics ≤5000 and Styles ≤1000 UTF-16 units, with no minimum. Tags, musical cues, Styles, Exclude and descriptive INFO are English; conversation supports Russian/English and lyrics the requested language. Russian phonetic examples remain native with English explanations.

personal/, prompts/, work/, caches and ZIP are excluded from Git and public handoffs. Publish this folder as the root after reviewing actual included files. ZIP requires a separate explicit command after final checks and must be placed directly in this root. No archive is generated by ordinary composition.

Song generation does not authorize rewriting protected skill files: [AGENTS.md](AGENTS.md), [file policy](references/FILES_spec.md). The explicitly authorized [SunoFill v3.12.0](tools/suno-fill.user.js) update reads the current grouped INFO; new chunks keep one ID and parent. Format tests do not prove rhyme, melody or actual voice/tag execution in Suno. Distribution license remains the owner's unresolved choice.
